# Artifact Invalidation Rules

- User-policy changes reopen intake and invalidate venue, research-program, and publication decisions.
- Science-profile or venue-profile changes reopen calibration and invalidate dependent design and
  publication contracts.
- L0 editorial Idea changes preserve compatible empirical evidence but reopen publication review.
- L1 scope changes invalidate affected research-program, experiment, claim, and publication evidence.
- L2-L4 estimand, population, mechanism, or core Idea changes invalidate the research program and all
  evidence that no longer answers the active Idea.
- Resource changes reopen research-program feasibility; protocol changes invalidate affected baseline,
  verification, pilot/full, mechanism, claim, and publication evidence.
- Repository/environment/backend changes invalidate the corresponding lock and executable evidence.
- Test-informed Idea evolution invalidates confirmation until independent evidence exists.
- Publication-contract changes reopen citation planning and every manuscript/figure/release artifact.
- Manuscript changes preserve research facts but reopen complete-draft, refinement, review, figures,
  compile, and release audit as applicable.

Rollback is dependency-based, not punitive. Old artifacts remain immutable history and can be reused
only when their Idea, contract, source, and hash bindings remain compatible.
