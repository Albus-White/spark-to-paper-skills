# Codex Execution Adapter

Codex owns bounded reasoning, web search, repository inspection, implementation, mechanism diagnosis,
manuscript revision, and isolated reviewer work. Deterministic scripts own schemas, hashes, manifests,
transition legality, invalidation, execution backend selection, timeouts, provenance and gate aggregation.
Every loop follows `bounded-execution-contract.md`; formal commands run through the backend locked by
`execution_backend.py`. Prefer parallel Codex subagents for Design Jury, implementation/protocol/
reproducibility review, mechanism skepticism, and Idea-evolution review. Pass raw artifacts, not the
implementer's conclusions. If subagents are unavailable, run the same lenses sequentially with strict isolation.
