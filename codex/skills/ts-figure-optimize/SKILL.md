# ts-figure-optimize

Read `../ts-research-lifecycle/references/bounded-execution-contract.md`.

The approved raster is immutable source evidence. This skill changes representation, not semantics.

## Workflow

1. Record source image hash, dimensions, caption, required labels, formulas, and active venue style.
2. Use the configured perception/OCR services to recover elements and reading order. Preserve uncertain
   regions rather than inventing text or geometry.
3. Reconstruct semantic SVG with editable text, shapes, edges, and embedded local assets. Export vector
   PDF and native PPTX.
4. Render SVG/PDF/PPTX back to pixels and compare the actual outputs with the source. Verify text,
   formulas, geometry, line/arrow connectivity, cropping, and editability.
5. Repair concrete measured defects only. Stop when checks pass, the same defect/hash repeats, quality
   regresses, or the bounded budget is exhausted.

Use the active venue font when specified; otherwise preserve the approved source's typography. Do not
force Times New Roman globally.

A whole-canvas raster embedded in SVG/PDF/PPTX is not semantic reconstruction. Allow a hybrid only
after explicit user approval when faithful vector reconstruction is not feasible, and disclose which
regions remain rasterized.

Keep the original raster and produce a report binding all outputs and reviews to hashes. A successful
conversion cannot override an unresolved scientific defect in the source image.
