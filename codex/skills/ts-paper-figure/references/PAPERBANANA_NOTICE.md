# PaperBanana attribution

The design of this Skill's reference-driven figure workflow and the retained venue style guides are
derived from PaperBanana / PaperVizAgent, studied at commit
`836455537e863b5a2f40dace487a782c0bc5ef94`.

PaperBanana is distributed under the Apache License, Version 2.0. The Skill does not import or execute
the PaperBanana repository. It re-expresses the Retriever, Planner, Stylist, Visualizer, Critic, and
multi-candidate contracts for Codex and retains the two style-guide texts with a clearly marked
suite-specific typography override.

Upstream project: `https://github.com/dwzhu-pku/PaperBanana`
